# Airlie Parks · AORA

Fact sheet of caravan parks in and around Airlie Beach, for Dingo Dave and the Australian Offroad Academy.

- Public page: https://aora73.github.io/airlie-parks/
- Stay ledger: https://aora-fieldstay.grok.me/

Drive times are measured from the Airlie Beach Lagoon. Photos are real and credited.
